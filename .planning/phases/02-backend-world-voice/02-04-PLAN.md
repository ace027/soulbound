<context>
Read `.planning/phases/02-backend-world-voice/02-CONTEXT.md`, then `backend/src/anthropic.ts`, the three route files, and the existing `backend/src/__tests__/contract.test.ts` from plan 02-02.

**Why mocked.** No API key exists in this environment. More importantly, these properties *should* be asserted without one: model IDs, `max_tokens`, `cache_control` placement, and schema wiring are request-construction facts, and a test that needs the network to check them is a worse test. Live verification in plan 02-05 covers only what mocking cannot: real schema-valid responses and actual cache hits.

Mock at the SDK boundary — intercept `messages.create` and capture the request object. Do not mock your own route handlers; that would test nothing.

The retrospective's motivation for pulling tests forward: three of Phase 1's eleven review defects were introduced *by fixes*, caught only by running things afterward. These tests are the net that was missing.
</context>
