**Why this module exists.** `PROJECT.md` records this codebase's recurring failure mode: drift between the three call sites, not any one being wrong. `generateIntroScene` once concatenated the system prompt into the user message and silently lost caching for months. One shared helper is the structural answer.

### Three corrections from plan critique — each was going to cost a cycle

**1. The client must be LAZY, not module-load.** `config.ts`'s `readApiKey()` throws **synchronously at import** when `ANTHROPIC_API_KEY` is absent. Verified:
```
$ unset ANTHROPIC_API_KEY; import config.js
THREW at import: Missing required environment variable: ANTHROPIC_API_KEY
```
`server.ts` already works around this with a deliberate `await import('./config.js')` inside `main()` — read that comment. If you construct the client at module load, `anthropic.ts` throws on import, and so does every route and every test file importing it. That contradicts this phase's premise that plans 01–04 run with **no key**, and plan 02-04's instruction that `npm test` must pass with the key unset.

Use a module-scoped `let client` populated on first call. Still a singleton, but importing the module must not require a key.

**2. Use the SDK's `zodOutputFormat`, not the raw schema.** `shared/`'s `WORLD_VOICE_JSON_SCHEMA` comes from bare `z.toJSONSchema()`. Measured against the SDK's own normalizer:
```
ours: $schema present, 4 enum occurrences
SDK : $schema stripped, enum -> description string
```
Anthropic's SDK ships `transformJSONSchema` precisely because raw Zod output is not safe to send. Import `zodOutputFormat` from `@anthropic-ai/sdk/helpers/zod` and build `output_config.format` from the **Zod schema**, not the pre-derived JSON Schema. Confirmed output: `type: 'json_schema'`, no `$schema`, no `enum`, `additionalProperties: false` preserved, plus a `.parse` helper.

`WORLD_VOICE_JSON_SCHEMA` stays exported for the startup drift guard, which reads property names only and is unaffected. **Do not add the Anthropic SDK as a dependency of `shared/`** — the frontend imports `shared/`, and the SDK must never reach the browser bundle.

**3. Set `output_config.effort` deliberately.** Confirmed in the installed SDK: `effort?: 'low' | 'medium' | 'high' | 'xhigh' | 'max' | null`. Opus 5 runs adaptive thinking **on by default**, and that reasoning consumes the same `max_tokens` budget raised to 16000 to avoid truncation. Leaving it unset means the default governs both quality and cost, and the ~$0.04/turn estimate that justified buying credits assumes nothing in particular. Pick a value, name it in a comment with your reasoning.
</context>
