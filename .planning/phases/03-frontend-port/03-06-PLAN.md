**This plan owns a `shared/` change.** `LogEntry` (shared/src/gameState.ts:121-127) has no
`etchingSkill`, but `WorldLog` renders `entry.etchingSkill.skill_name` — the skill-etching reveal,

`ns.soul_etching_text`, `ns.skill_name`, `ns.tier`, `ns.mastery`, `ns.description` off it. Under

`npm run build -w @soulbound/shared` before typechecking the frontend (`@soulbound/shared` resolves
via `dist/`).

**Inline styles port verbatim.** PROJECT.md puts styling-system changes out of scope. The same button
style repeats several times — leave it. Extracting it is a different phase's decision.

**One confirmed defect to fix.** `WorldLog`'s root (legacy line 659) is
`{ flex: 1, overflow: "auto", padding: ... }` with **no `minHeight: 0`** — a direct CLAUDE.md #3
violation, verified by reading the file. Add `minHeight: 0`. A literal verbatim port would carry the
bug forward; constraint #3 wins, and R12 is explicitly about fixing bugs found during the port.

**The six `<style>` blocks are all in screens (1051, 1189, 1263, 1338, 1354, 1410), none in
components** — so a `<style>` grep scoped to `components/` cannot fail and is not a check. Plans
03-07 and 03-08 own that assertion. Do not re-introduce them anyway. Phase 1 extracted all 7 keyframes (including
`cardHover`) to `index.css` and put the Google Fonts `<link>` in `index.html`. Re-injecting them is
R12's second bug returning.

Legacy CSS drift note carried from Phase 1: the six duplicated style blocks were **not** identical —
`breathe`, `glowPulse`, `etchIn` and the scrollbar thumb width differ between copies, and `index.css`
resolved each by plurality. If a component looks subtly off against the artifact, those four rules are
the first place to look. There is no single "correct" original to diff against.
