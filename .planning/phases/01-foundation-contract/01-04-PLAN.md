<objective>
Stand up the frontend service: Vite + React + TypeScript, fonts loaded correctly from the start, an API proxy to the backend, and a Dockerfile. No game UI yet — Phase 3 ports the components.
</objective>

<context>
The artifact was a single file with exactly one import (`react`), one default export, no ReactDOM mount, no `index.html`, and no bundler entry. There is nothing to extend — this scaffold is built from scratch and Phase 3 ports logic into it.

Two legacy problems get fixed here rather than carried forward (part of R12):
- **Google Fonts** were loaded via `@import url(...)` inside a `<style>` tag rendered by six different screens, re-injected on every render. Load Cinzel and EB Garamond once, via a `<link>` in `index.html`. Check the legacy `<style>` blocks (around lines 1052, 1190, ~1263, 1338, 1355, 1411) for the exact font families and weights actually used — match them, don't approximate.
- **Direct Anthropic calls.** No frontend code may ever target `api.anthropic.com`. The dev server proxies `/api` to the backend; the key lives server-side only.

The remaining R12 bug — `window.innerWidth` computed during render with no resize listener (legacy line 1348) — belongs to Phase 3, where the responsive layout is actually ported. Do not attempt it here.

Read `.planning/phases/01-foundation-contract/01-CONTEXT.md` first.
</context>
