  - `sample-usage.log`: seven lines in the real `[anthropic:usage]` format (four `prologueBeat`, one `prologueProfile`, one `uniqueSkill`, one `introScene` with a non-zero `cache_creation_input_tokens`) with plausible token counts, used only to test the script; start the file with a comment line `# sample, not real usage`.
