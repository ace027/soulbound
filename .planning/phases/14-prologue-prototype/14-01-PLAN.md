Beside you, a second soul flickers, smaller than you, fraying at its edges. Ahead there is a seam of ember-light: a doorway that can carry one soul across at a time, and it is narrowing. Behind you, something cold has turned toward the sound of you both. What do you do?" (em dash U+2014; identical to the OPENING constant in `.planning/experiments/2026-10-01-prologue-test/run-v2-1.mjs`).
- `export const PROLOGUE_BEAT_COUNT = 4`, `PROLOGUE_ENTRY_MAX = 2000`, `PROLOGUE_NARRATION_MAX = 1500`, `PROLOGUE_PROFILE_FIELD_MAX = 600`.
- `export const PROLOGUE_CANONS = ['traits', 'scene'] as const`; `export const PrologueCanonSchema = z.enum(PROLOGUE_CANONS)`; `export type PrologueCanon`.
- `export const PrologueHistoryEntrySchema = z.strictObject({ role: z.enum(['narrator','player']), text: z.string().min(1).max(PROLOGUE_ENTRY_MAX) })`; `export type PrologueHistoryEntry`.
- `export const PrologueBeatRequestSchema = z.strictObject({ history: z.array(PrologueHistoryEntrySchema).min(2).max(8) }).superRefine(...)`: entry 0 must have role `narrator` and text exactly `PROLOGUE_OPENING`; roles must strictly alternate narrator, player, narrator, player...; the last entry must be role `player`; the player count is 1-4. Each violation adds one issue with a path pointing at `history` and a message naming the rule.
- `export const PrologueProfileRequestSchema = z.strictObject({ history: z.array(PrologueHistoryEntrySchema).length(9), canon: PrologueCanonSchema.default('traits') }).superRefine(...)`: the same opening/alternation rules, and the last entry must be role `narrator` (so exactly 4 player entries).
- `export const PrologueNarrationSchema = z.strictObject({ narration: z.string().min(1).max(PROLOGUE_NARRATION_MAX) })` (what the model returns for a beat).
- `export const PrologueBeatResponseSchema = z.strictObject({ narration: z.string().min(1), beat: z.number().int().min(1).max(4), final: z.boolean() })` (what the route returns); `export type PrologueBeatResponse = z.infer<typeof PrologueBeatResponseSchema>`.
- `export const PrologueProfileSchema = z.strictObject({ nature, drive, flaw, memory, bond })`, each `z.string().min(1).max(PROLOGUE_PROFILE_FIELD_MAX)` (both the model's output schema and the route response); `export type PrologueProfile`.
- A header comment in the style of `worldVoice.ts` stating: these schemas are NOT part of `WORLD_VOICE_JSON_SCHEMA` and constraint #4's field list is unchanged.
