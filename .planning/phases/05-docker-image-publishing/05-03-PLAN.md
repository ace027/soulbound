<action>

  `clearPassphrase()` and notify listeners before throwing. The thrown error message is
  `"Passphrase required"` (the backend's own envelope message).
- Add `export async function checkAccess(): Promise<'ok' | 'required' | 'unknown'>`. It sends a GET
  to `ACCESS_CHECK_PATH` with the header if one is stored. 204 gives `'ok'`. 401 with a
  `PASSPHRASE_REQUIRED` envelope gives `'required'`. **Anything else, including a network error,
  502, HTML or 404, gives `'unknown'`.** It never throws.
- Update the module header's gate list (`:148-150`) with one line about the header.

- 401 `AUTHENTICATION_FAILED` does **not** clear storage;
- 429 `TOO_MANY_REQUESTS` surfaces its message and doesn't clear storage;
- `checkAccess` maps 204, 401 with the code, 401 without the code, 502 `text/plain`, a network
  rejection and 200 HTML to `ok`, `required`, `unknown`, `unknown`, `unknown` and `unknown`.
