<task id="1">
<action>
Write `scripts/smoke-image.sh` (bash, `set -uo pipefail` — **not** `-e`, because every check must run
even after one fails; executable per protocol 5; header comment on purpose and usage). Keep a
failure counter, and at the end print `N/7 passed` and `exit 1` if N < 7. A setup failure (container
won't start, or health times out) exits immediately; the checks don't. Usage: `scripts/smoke-image.sh <image>`.

It:
- picks a free port and a random passphrase (≥12 chars);
- sets a bogus `ANTHROPIC_API_KEY` of the form `sk-ant-smoke-not-a-real-key`;
- runs the container detached with the hardening flags, `RATE_LIMIT_PER_MINUTE=3` and
  `ALLOWED_HOSTS`;
- sets `trap` to always remove the container;
- polls `/api/health` until it returns 200 (timeout 30 s).

Then it checks, printing `PASS`/`FAIL <check>` for each:

| # | Request | Expected |
|---|---|---|
| 1 | health | 200 |
| 2 | `/` | 200 with `text/html` |
| 3 | `/api/access` without a header | 401 with `"code":"PASSPHRASE_REQUIRED"` |
| 4 | `/api/access` with `Authorization: Bearer <p>` | 204 |
| 5 | `/api/x` with the header | 404 with an `application/json` content type |
| 6 | four more `/api/access` calls | a 429 with `"code":"TOO_MANY_REQUESTS"` and a `Retry-After` header |
| 7 | `docker logs` | does not contain the passphrase |

Count the requests: checks 3-6 all hit the limiter, so work out when the 4th request in the window
lands and assert on it. Don't guess.

Run it locally against `soulbound:05-04` (or a fresh build) with dockerd started. Save the full
output to `evidence/smoke-image-local.txt` along with the image ID and date.
</action>

- Jobs: `test` (same steps as CI); `smoke` (needs test; same as the CI smoke job); `publish` (needs
  smoke).
- `publish` steps, in order:
  1. checkout;
  2. **version agreement**: a `node -e` script reads all four `package.json` versions and fails
     naming any mismatch;
  3. set `VERSION` and `IMAGE` (lowercased);
  4. `docker/setup-qemu-action@v3`, `docker/setup-buildx-action@v3`;
  5. `docker/login-action@v3` to `ghcr.io` with `github.actor` / `secrets.GITHUB_TOKEN`;
  6. **existence check**: `docker buildx imagetools inspect "$IMAGE:$VERSION"`. Exit 0 means fail
     ("already published"). Otherwise capture stderr: if it matches
     `not found|manifest unknown|name unknown` (case-insensitive), proceed; **else fail** and print
     stderr. Put the fail-closed reasoning in a comment. **Write it so it survives `bash -e`**, the
     Actions default: `if out=$(docker buildx imagetools inspect "$IMAGE:$VERSION" 2>&1); then echo
     "::error::$IMAGE:$VERSION already published"; exit 1; fi`, then match `$out`. A bare
     `out=$(…)` exits the step on the non-zero status before the match runs, so every dispatch would
     fail;
  7. `docker/build-push-action@v6` with `platforms: linux/amd64,linux/arm64`,
     `file: backend/Dockerfile`, `push: true`, tags
     `${{ env.IMAGE }}:${{ env.VERSION }}` and `${{ env.IMAGE }}:latest` (inside `with:` a shell
     `$VAR` is passed literally), and OCI labels (`org.opencontainers.image.source`, `.revision`, `.version`).
- Pin the actions to the major versions above.
</action>
