<task id="1">
<action>
Create `backend/src/accessGate.ts` with a header docstring on the why: the limiter runs before the
gate so guesses are throttled; both run before body parsing so unauthenticated bodies are never
parsed; the codes are distinct from the upstream ones. It exports:
- `createRateLimiter({ perMinute, now })`: a fixed 60-second window in a `Map<string, {count,
  windowStart}>`, keyed on `req.ip ?? 'unknown'`, pruning expired entries when a new window starts.
  Over the limit it returns 429 with the spec's body, a `Retry-After` integer ≥ 1 (seconds until the
  window ends), and `TOO_MANY_REQUESTS` from shared.
- `createAccessGate(check)`: parses `Authorization`, requires scheme `Bearer` (case-insensitive
  scheme, exact token), and calls `check(token)`. On failure it returns 401 with the spec's body and
  `WWW-Authenticate: Bearer realm="soulbound"`. It must not log the header value.

Write `backend/src/__tests__/accessGate.test.ts` for the units, using an injected `now`:
- request N+1 in a window returns 429 with an integer `Retry-After`;
- the window resets after 60 s;
- separate IPs get separate buckets;
- an undefined `ip` goes to the `'unknown'` bucket;
- missing, wrong-scheme, wrong-token and empty-token requests each return 401;
- the correct token calls `next()`.
