Express static behaviour to rely on: `express.static(dir, { index: 'index.html' })` serves files. The
fallback is `app.get(/.*/, (_req, res) => res.sendFile(path.join(STATIC_DIR, 'index.html')))`,
registered last before the error handler. Express 5 path syntax: `app.get('*')` is **not** valid in
Express 5 (path-to-regexp v8), so use a regex or `'/{*splat}'`. Verify which one works with a test,
not from memory (AI-3).
